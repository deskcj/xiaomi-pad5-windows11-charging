# SK-Charging1853 — MMIO lifetime TCPM

Тестово подписан один клиент qcusbctcpm8150, INF1.0.1853.0.
Файлы SYS/INF/CAT в package; не установлены. REVIEW-1853-RU.md содержит
изменения, результаты и оставшиеся препятствия. Полное питание/USB ещё
не исправлено и не проверено на железе. Installed PEP2140 здесь не заменяется.

FUNCTION-CHECKLIST-RU.md — критерии будущей аппаратной приёмки.
Исходники src/client_repair.c; тесты и инструменты — tests и tools.
Reproduce.ps1 запускается только в новой папке без предыдущих build/package.
Он не устанавливает и не активирует драйвер. Package-1853.ps1 подписывает
уже проверенный пакет существующим сертификатом разработки.

Для joint-теста также нужен соседний candidate-1852-alert-rundown/next-pep
с его проверенным pep_lifetime.obj, исходником, reference и harness.
Модуль PEP в этой папке не перекомпилируется и не заменяется. Его хеши
строго сверяются аудитором. Это зависимость локального исследовательского
проекта; оригинальные Qualcomm SYS/INF нужно предоставить по закреплённым
хешам. В публичном GitHub архиве нет raw драйверов, дампов или ключей.

Старые backend/battery исходники и тесты оставлены только как справочный
материал1851; они не входят в новый клиентский пакет1853.
