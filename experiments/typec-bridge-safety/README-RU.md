# Type-C bridge: только офлайн-исследование

Ничего не устанавливает, не сбрасывает USB, не читает и не пишет регистры
реального устройства. Unicorn исполняет копии ARM64-инструкций с моделями
WDF/backend/WPP. Кандидаты unsigned и не проходили загрузку Windows.

Исходный qcusbctcpm8150.sys должен иметь SHA256:
7C63F4A4B8A9EE0F49B427B6AC94867D2475E02F85D92D5FBCFE4A8AA1804067.
Скрипты сборки откажутся от другого файла. Оригинал и готовые SYS не
включаются в публичные GitHub downloads. Публичны скрипты и результаты.

Для переноса исследования задайте путь к своей копии точного оригинала:

```powershell
$env:NABU_TYPEC_SOURCE='D:\research\qcusbctcpm8150.sys'
# PYTHONPATH должен указывать на изолированные pefile/capstone/unicorn.
python emulate_transport.py
python emulate_waitlock.py
python build_test_fix2.py
python build_test_fix3.py
python test_lifecycle_guards.py
```

Порядок важен: fix3 принимает точный результат fix2. Повторный запуск не
переписывает отличный кандидат. Скрипты не являются установщиком драйвера.
Зависимости исследования: pefile2024.8.26, capstone5.0.6, unicorn2.1.4.

Fix2: пропуск backend status и not-ready lock leak;1260 парных сценариев,
8 повторных последовательностей,518 native unwind-контекстов.
Fix3: ещё пять полных64-битных относительных таймеров и пять строгих
проверок результата WdfWaitLockAcquire.144 полных случаев двух callbacks
и270 случаев префиксов всех пяти callers. Native unwind:344+518.

Все передаваемые драйверу handles/память/результаты в этих моделях вымышлены.
Пройденные проверки не гарантируют отсутствие BSOD и исправление cold attach,
зарядки, Code43, гонок IRQ или непрерывности SSD. Три больших lifecycle
сценария после успешного acquire целиком не исполнены. IRQL/lifetime в
живом ядре не проверены. Положительный timeout в старой error-ветке WPP
ещё может быть записан как0; это не исправлено.

В safetyfix3 может лежать промежуточный REJECTED-файл. Он НЕ кандидат:
проверка выявила оставшуюся32-битную запись таймера. Он исключён из архива.

Основной разбор: ../TYPEC-DEEP-DIVE-RU.md. В репозитории:
docs/TYPEC-BRIDGE-SAFETY-2026-10-27.md.
На планшете следует сохранять1840/oem92 и USB-C1680/oem110: владелец
запретил установки и физические тесты. Автоматического активатора нет.
