# SK-Charging1852 — офлайн кандидат TCPM

Один клиент qcusbctcpm8150, INF1.0.1852.0. Подписанный комплект SYS/INF/CAT
находится в package. На планшет не установлен. Не является полным исправлением
питания: PEP2140, ghost AC и непрерывность SSD остаются открытыми задачами.

Читайте REVIEW-1852-RU.md и FUNCTION-CHECKLIST-RU.md. Числа проверок,
хеши, границы доказанного и препятствия для установки указаны там.

Основной маршрут: tools/Reproduce.ps1 в НОВОЙ папке без build/package/reproduce.
Он компилирует и проверяет unsigned клиент, не устанавливая драйвер.
После проверки tools/Package-1852.ps1 подписывает пакет существующим
сертификатом разработки. Исходный OEM INF меняется только в DriverVer.
Старые backend/battery файлы и тесты из1851 оставлены как справочный материал;
они не входят в комплект1852 и не выполняются новым маршрутом сборки.

next-pep содержит отдельный лабораторный модуль следующего исправления PEP.
Это C/COFF с тестами контракта на оригинальном PEP/провайдере; SYS/INF/CAT
для него не создавались. Он не подходит для установки. Подробности в
next-pep/README-RU.md. Изменять работающий драйвер через эти скрипты нельзя.
