# PMIC fix20r2 / 1.0.1844.0 — эксперимент

Сборка для Xiaomi Pad 5 nabu, ACPI QCOM05E5. Основа: китайский fix20,
с собственным C-кодом исправления и восстановленными данными исходного драйвера.
Это не полностью новый исходный код Qualcomm.

Изменение r2 относительно установленной r1/1843: проверка готовности выбранного
логического порта (0 или 1); неподдерживаемые индексы отклоняются до чтения таблицы.
Backend nabu использует индекс 1. Ранее guard ошибочно всегда проверял порт 0.
Состояние этих указателей на реальном устройстве не измерено: исправление ошибки
кода не доказывает, что именно она вызвала пропадание накопителя.
Эвристика fix20 оставлена только для индекса 0. PD/QC и быстрая зарядка не добавлены.
Остальные компоненты USB-C и battery miniclass 1680 не изменяются.

Проверен окончательный подписанный SYS: 2072 сценария исполнения ARM64,
130 нативных проверок RtlVirtualUnwind, Ghidra-декомпиляция hook/guard.
В сборщике исправлено сохранение всех семи пар .pdata/.xdata из MSVC COFF.
Предыдущий неполный вариант был отклонён до подписи/установки.
Регрессия r1 через исправленный сборщик дала исходный хеш r1.
Проверки не гарантируют отсутствие BSOD и не заменяют загрузку/тесты на планшете.

Install-PmicPackage.ps1 по умолчанию делает Inspect без установки.
Stage и Activate требуют явного флага эксперимента, повышения прав,
существующего доверенного тестового сертификата и test signing.
Activate требует записанный Stage и внешнюю копию отката; без перезагрузки.
Установка производится текущей сессией после резервирования текущей 1843.
Не запускать повторно и не удалять устройство вручную.

Restore-ExperimentOffline.ps1 поддерживает ровно известные хеши исходных версий,
включая нашу подписанную r1. Шесть проверок выбора snapshot/guard пройдены.
Фактический offline Apply не испытывался.
Снимки SYSTEM/BCD и приватные ключи в этот архив не входят.
Отдельный Type-C lockfix не входит и не устанавливается.
