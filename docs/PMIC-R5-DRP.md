# PMIC r5 / 1.0.1847.0 — эксперимент сохранения DRP

На r4 первая загрузка и новый read-only протокол прошли. При первом
подключении хаба с зарядкой и SSD зарядки нет: 1509=26, 150B=C9,
1544=04 (SOURCE-only), 1140=01 (OTG включён). Перед этим журнал снимал
1509=07 при отсутствии CC attachment. Старый fix20 переписывает запрос
DRP в SOURCE для всего диапазона полных байтов 5..34. Источник конкретного
вызова роли в этой записи не трассировался; это кандидат причины.

В r5 удалена только эта подмена. Проверка выбранного порта, сохранение
регистров/стека, ошибки SPMI и приватное чтение r4 сохранены. Явные запросы
SOURCE/SINK сохранены. Ветка DRP использует прежний путь: выключить OTG,
затем установить DRP/Try.SNK. Это может прервать питание USB при переходе
роли; первые аппаратные тесты выполняются без копирования данных.
Непрерывная работа SSD, PD, быстрая зарядка и отсутствие BSOD не доказаны.

Подписанный SYS: 314BBF81ED5263388EFCD8316E0CC8C030894B98B7348089C35D6174E55685B3.
3907 сценариев реальных ARM64 инструкций, 882 диагностических,
19 интеграционных запросов исходного dispatcher и 307 native ARM64 unwind
прошли. Каталог и членство SYS проверены. Отчёты в build/.
Это тестовая подпись, не WHQL. Miniclass батареи остаётся 1680.

install.cmd / Install-PmicPackage.ps1 по умолчанию только Inspect.
Stage и Activate — отдельные режимы с AcknowledgeExperimental.
Перед активацией нужны полный SYSTEM до Stage, исходный пакет,
проверенная копия на внешнем диске и доступ к офлайн Windows.
Установщик не удаляет устройство, не меняет BCD/сертификаты и не
перезагружает Windows. Офлайн откат восстанавливает весь SYSTEM,
поэтому отменяет также последующие системные изменения.

Ни один офлайн тест не гарантирует успешную загрузку ядра.
