# Аппаратная приёмка — промежуточные результаты

Перед началом: подтверждённый доступ к recovery, проверенная внешняя копия последнего полного SYSTEM/BCD и пакета базы, стабильная батарея 1680. Не начинать с почти разряженной или перегретой батареей. Для сравнения мощности — SOC примерно 30–80%, одинаковые адаптер/кабель/нагрузка и внешний измеритель.

| Проверка | Критерий | Результат |
|---|---|---|
| Первая загрузка без хаба | Загрузка Windows, PMIC/батарея без ошибок | Один запуск прошёл; хаб подключён после входа со слов владельца; 1843/1680, ProblemCode=0 |
| Процент и питание без кабеля | Правдоподобный SOC, переход к разряду | Pending |
| Зарядка напрямую | Фактический заряд, корректный переход статуса | AC определён; три цикла пропадания/возврата статуса. Владелец сообщил, что после вставки кабель не трогал; причина не установлена. SOC 100%, прирост энергии не проверен; приёмка pending |
| Только USB-накопитель | Устройство доступно, чтение сохранённого тестового файла | Pending |
| Хаб без зарядки | Перечисление устройств, правильное питание | Pending |
| Хаб + зарядка без SSD | Power-sink при data-host, стабильное питание | Pending |
| Хаб + зарядка + SSD | Одновременная работа без disk/USB-сбоев | Короткий прогон прошёл, SOC 96→97%, три uncached-чтения; длительная проверка и hotplug pending |
| Отключить/вернуть зарядку на хабе | Корректные переходы без потери данных/перезагрузки | FAIL при отключении: пропали хаб и SSD; возврат зарядки восстановил оба без перезагрузки |
| Непрерывный ввод-вывод при снятии/возврате зарядки | Нет исчезновения SSD, сброса USB или обрыва операций | Требование владельца; текущая 1843 не проходит снятие питания. Сначала проверка чтением, копирование важных данных не использовать |
| Безопасно отключить/вернуть хаб | Повторное перечисление USB и возврат питания | Владелец сообщил об успешном возврате; три чтения после него прошли, сам момент отключения в журнал не попал |
| Обе ориентации USB-C | Эквивалентная работа | Pending |
| Сон/пробуждение | Восстановление USB/заряда | Pending |
| Тёплый перезапуск и холодная загрузка, с хабом/без | Повторяемость старта | Pending |
| Контролируемое восстановление | Возврат к точным исходным хешам/привязке | Pending |

Перед отсоединением накопителя завершить записи и безопасно извлечь его. Логи писать на внутренний диск. Не использовать бенчмарки записи важных данных. Сначала короткий прогон, затем повторения каждого перехода. Число успешных повторов публиковать вместе с моделью адаптера/кабеля/хаба и SOC.

Если появляется bugcheck, зависание, потеря накопителя или батарея перестаёт определяться — остановить испытание, сохранить внутренний лог/дамп и откатить кандидат. Не заменять батарейный miniclass и не сбрасывать PMIC многократно, маскируя первоначальный отказ.

Успех этой матрицы снизит риск, но не доказывает абсолютного отсутствия ошибок при любых аксессуарах и состояниях.
