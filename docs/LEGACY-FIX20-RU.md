# Исходный fix20 — пакет с исправленным установщиком

**Код драйвера не исправлен.** Это временный legacy-вариант с теми же известными ошибками измерений и обработчика USB, что у исходного китайского fix20. Для исследования предпочтителен отдельный fix20r1; его аппаратная проверка тоже не выполнена.

Код и данные исходного SYS сверены побайтно по всем PE-секциям. Файл переподписан существующим тестовым сертификатом, чтобы SYS и новый каталог имели проверяемую тестовую подпись. Поэтому SHA-256 полного переподписанного файла отличается от оригинального `995551…`; оригинальный архив в проекте не изменён.

Пакет содержит настоящий INF `QCOM05E5`, SYS/CAT и установщик на штатном pnputil. По умолчанию — только просмотр. Не требуется предварительно удалять Qualcomm PMIC Extension; установщик сам не включает host mode, не меняет BCD/сертификаты/батарею и не перезагружает систему.

```powershell
.\Install-PmicPackage.ps1 -Mode Inspect
```

Stage/Activate, тестовое подписание, резервные копии и офлайн-откат работают так же, как у fix20r1. **Ничего не активировать без подготовленного доступа к recovery.** Батарея должна оставаться 1680. Пакет не является гарантированно стабильным решением и не должен рекламироваться как исправление всех USB/зарядных проблем.

Публичный CER не содержит закрытого ключа. Установщик его не импортирует. При будущей установке на другую систему доверие сертификату и совместимость загрузочной политики должны быть рассмотрены отдельно; отключение проверок целостности автоматически не выполняется.
