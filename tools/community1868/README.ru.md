# SK-Charging 1868 — Xiaomi Pad 5 / Windows 11 ARM64

[English](README.md) · [Проект и актуальный статус](https://github.com/deskcj/xiaomi-pad5-windows11-charging)

В архиве — точные файлы драйверов зарядки, проверенные на планшете проекта. Это экспериментальный пакет сообщества для **nabu**, а не полный набор драйверов Windows.

## Установка

1. Нужны Windows 11 ARM64, установленные базовые драйверы nabu и **уже активный Test Mode**. [Инструкция проекта nabu по загрузке и подписи](https://github.com/erdilS/Port-Windows-11-Xiaomi-Pad-5/blob/main/guide/English/disable-secureboot-en.md).
2. Полностью распакуйте ZIP в папку на внутреннем диске Windows планшета. Сохраняйте файлы вместе; не запускайте установку прямо из ZIP.
3. Дважды нажмите **Install.cmd** и разрешите запрос администратора. Откроется штатный Windows PowerShell; Python, SDK и ручной выбор INF не нужны.
4. Дождитесь **Driver set staged; reboot manually**. Сохраните работу, безопасно извлеките USB-накопители и перезагрузитесь вручную. Если появилась ошибка, сохраните протокол установки: это не означает успешную установку.
5. После перезагрузки запустите **Diagnose.cmd**. У пяти строк должны совпасть версии и хеши, `Running=True`, `ProblemCode=0`.

Установщик проверяет модель, ARM64, активный Test Mode, хеши и подписи. Перед подготовкой четырёх обновляемых пакетов к перезагрузке он сохраняет и проверяет предыдущие пять пакетов на внутреннем диске. Совместимый battery miniclass остаётся на месте. В хранилища Windows Root/TrustedPublisher при необходимости добавляется **только открытый сертификат разработки из архива**; закрытого ключа здесь нет. BCD, Secure Boot, драйверы камеры не меняются; автоматической перезагрузки нет. Повторная установка совпадающего набора ничего не меняет; автоматическое понижение версии запрещено.

Базовый battery miniclass должен соответствовать версии `1.0.1680.0` и хешу SYS в `manifest.json`. Его неизменённые INF/SYS/CAT находятся в `reference/` и **не устанавливаются**. Они нужны для идентификации проверенной базы; вручную ставить reference не нужно. Пакет не предназначен для других планшетов и неполной базовой установки драйверов.

Предварительная проверка без установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -CheckOnly
```

## Диагностика и возврат

**Diagnose.cmd** сохраняет ZIP в `%LOCALAPPDATA%\SK-Charging-Diagnostics`: версии, хеши и состояние драйверов, ошибки устройств, USB/накопители, недавние относящиеся к проблеме события System и документированную телеметрию батареи. Скрипт не устанавливает и не сбрасывает устройства, не вызывает частные управляющие PMIC IOCTL и не отправляет отчёт в сеть. Перед публикацией просмотрите архив: USB ID и сообщения событий могут содержать серийные номера и локальные пути.

Для пяти минут замеров батареи откройте PowerShell в папке:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Diagnose.ps1 -Seconds 300
```

Мощность и ёмкость — **телеметрия драйвера, а не показания внешнего USB-измерителя**. При 100% ёмкость может не меняться.

Протоколы и проверенные копии находятся в `%ProgramData%\SK-Charging\Install-*`. Для возврата безопасно извлеките и физически отключите USB-накопители, затем запустите **Restore.cmd внутри нужной папки резервной копии `Previous`**, которую указал Install. Restore.cmd из основного архива выбирает последнюю сохранённую копию. Возврат может перезапустить USB/зарядку; он выбирает четыре сохранённых драйвера и оставляет miniclass на месте. Затем перезагрузитесь вручную. Скрипты восстановления и все 15 прежних INF/SYS/CAT останутся даже после удаления ZIP. Если Windows не загружается, используйте обычное восстановление Windows/офлайн-восстановление драйверов с этими файлами.

## Что проверено и какие ограничения

- ✅ Переключение прямой зарядки ↔ USB-C SSD; распознавание повербанка и работа флешки через OTG в проверенных последовательностях.
- ✅ Acer HY41-T9 с зарядкой и Kingston XS2000; возврат зарядки после подключения PD-кабеля обратно.
- ⚠️ При снятии PD-зарядки с Acer HY41-T9 SSD кратко отключается и появляется снова. **Баг остаётся.** Не переключайте питание хаба во время записи на диск; при необходимости используйте безопасное извлечение.
- ⚠️ Зафиксированы фиксированные USB PD запросы с лимитом контракта до 18 Вт; фактическая максимальная мощность питания/зарядки не подтверждена.
- ❌ PPS и доказанное бесшовное переключение питания/FRS в этой сборке не обеспечены.
- ⚠️ Не гарантирована работа каждого хаба, зарядника, OTG-устройства, сценария загрузки, сна и нагрузки.

`FILES-SHA256.json` содержит хеши файлов архива. `manifest.json` — версии пакетов и хеши драйверов. Номер набора — **1868**; версии INF компонентов разные, а PE FileVersion может сохранять старое значение.
